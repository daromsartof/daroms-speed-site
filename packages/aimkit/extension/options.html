AimKit

Vise un élément de ta page en dev : son HTML, son CSS avec fichier:ligne et sa source sont écrits dans le projet, et Claude Code les lit.

Mise en route

  1. 1

    Lancer le bridge dans le projet

    À la racine du projet, là où tourne Claude Code : aimkit

    • 2

      Lier l'extension au bridge

      Ouvre le lien affiché au premier démarrage du bridge (ou par aimkit token), ou colle son jeton. Le jeton est le même pour tous tes projets.

    • 3

      Autoriser les captures d'écran

      Les aperçus des éléments en ont besoin. Chrome ne laisse une extension capturer l'onglet qu'avec l'accès à tous les sites, ou juste après un clic sur son icône.

    • 4

      Facultatif : Claude Code sans coller de ligne

      Dans le projet, une fois. Ensuite : « regarde le dernier élément que j'ai visé ».

      claude mcp add aimkit -- aimkit mcp

    Réglages

    RaccourcisAlt+Maj+E viser, Alt+Maj+C capture avec contexte, Alt+Maj+D afficher le dock

    Sites où le dock apparaît

    D'office sur localhost, 127.0.0.1, *.localhost et *.test. Pour une préproduction, ajoute son origine : Chrome demande la permission. Ailleurs, un clic sur l'icône de l'extension l'affiche sur l'onglet courant.

    • http://localhost
    • http://127.0.0.1
    • http://*.localhost
    • http://*.test

      Plusieurs projets ouverts

      Chaque projet a son bridge. L'extension choisit celui dont la liste « origins » contient le site. Sinon, associe le site à un projet ici : l'association tient même si le port du bridge change.
