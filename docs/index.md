# daroms-speed-site

> A Next.js framework and Claude Code workflow that turns a brief into a varied, production-grade website at low token cost.

daroms-speed-site (dss) is built for producing websites on a line: agencies, freelancers and studios who ship many
sites and want each one to look designed for its business, rank, load fast and stay secure.

## What you get

- A **site template** on Next.js 16, React 19, Tailwind CSS v4 and TypeScript, static by default, deployable to
  Cloudflare Workers (OpenNext), Vercel or Docker.
- **Design DNA**: every site rolls an archetype, a type pairing, an accessible OKLCH palette, a grid, a texture, a motion
  profile and a 3D level, avoiding combinations used by previous sites.
- A **section registry** copied into each site (owned code) and versioned **core packages** for SEO, security, data,
  motion and 3D.
- The **dss CLI**: deterministic generators for pages, sections, themes, modules, databases and deployments.
- An **AI layer** for Claude Code: a 57-line kernel, rules loaded by file path, forked Sonnet/Haiku skills, guard hooks
  that refuse bad writes, a prompt router, a factory brain shared by all sites, and cost reports.
